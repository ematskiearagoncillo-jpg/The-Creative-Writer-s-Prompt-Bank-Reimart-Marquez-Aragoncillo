Overcoming Writer's Block

Prompt 1

Set a timer for ten minutes and write without stopping or editing.

Prompt 2

Write the scene you are avoiding, but badly, on purpose.

Prompt 3

Change the setting: write by hand, outdoors, or in another room.

Prompt 4

Describe your character's pockets in detail.

Prompt 5

Skip ahead and write the ending, then work backward.

Prompt 6

Take a walk, then return and write the first thing you thought of.
